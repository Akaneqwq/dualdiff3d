# DualDiff3D Project Page

Static project page for:

**DualDiff3D: Dual Structure-Appearance Diffusion Priors for Reliability-Enhanced 3D Gaussian Splatting**  
European Conference on Computer Vision (ECCV), 2026.

## Publish with GitHub Pages

1. Push this directory to a GitHub repository.
2. Open **Settings → Pages** in the repository.
3. Select **Deploy from a branch**, then choose the branch and `/ (root)`.
4. Save and wait for the deployment to finish.

No build step or external dependency is required.

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
